# Sistema de Relatórios Climáticos

Projeto desenvolvido em Dart para leitura, processamento e geração de relatórios climáticos a partir de arquivos CSV.

O sistema realiza a comparação de informações climáticas dos estados de São Paulo e Santa Catarina, permitindo consultar dados de temperatura, umidade e direção do vento.

## Funcionalidades

- Leitura de arquivos CSV com dados de sensores climáticos

- Conversão dos dados em objetos Dart

- Menu interativo via terminal

- Geração de relatórios de:

  - Temperatura

  - Umidade

  - Direção do vento

- Exportação dos relatórios em arquivos `.txt`

- Exibição de informações coloridas no terminal
